Data:
collection of raw facts, figures and symbol
it is meaningful and unprocessed

Information:
the data is processed or meaningful data 
ex: st = 101;

File Management System(FMS):
It is used before creation of database to store the data 

key functions of FMS. 
1. create file
2. open file
3. delete file
4. read file
5. share data
6. to provide access

Drawbacks of FMS.
1. data inconsistency
2. less security
3. data redundancy
4. backup/recovery
5. data manipulation

Database:
It is a tool, used to store the data 

Management System:
To manage data like retrieve, update, delete data


DBMS:

It stands for database management system, it is a software.
the main purpose of DBMS is used to store data in permanently
and manage/manipulate the given data.

Advantages of DBMS:
1. reduce data redundancy
2. to provide more security
3. to improve data inconsistency
4. to maintain readability

Types:
1. NoSQL DBMS: 
   The data is stored into the unstructured format
   Ex: mongo-dB, post-grace SQL
2. RDBMS: 
   It is stands for relational DBMS
   In RDBMS the data stored in rows and columns like table
   Ex: MySQL, oracle, etc...

MySQL:
